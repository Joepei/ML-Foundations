# ML Foundations

ML Foundations is Joe Pei's technical writing site on machine learning fundamentals, deep learning systems, and transformer implementation details.

The site is meant to connect three layers that are often learned separately:

- the intuition behind an ML or deep learning concept
- the math and tensor shapes that make the concept precise
- the implementation details that matter when building or training the system

Live site:

```text
https://joepei.github.io/ML-Foundations/
```

## What Is On The Site

The site currently has two main tracks.

**Machine Learning**

- supervised learning fundamentals
- linear models
- regularization
- tree-based models

**Deep Learning and Transformer Systems**

- tokenization and byte-pair encoding
- transformer architecture
- training transformer language models
- GPU systems and utilization
- transformer resource accounting


## Repository Structure

```text
docs/             Published Markdown pages for the website
mkdocs.yml        MkDocs configuration and navigation
site/             Generated build output
Deep Learning/    Source notes and implementation material
Machine Learning/ Source notes and notebooks
scripts/          Utility scripts for site/content workflows
```

Most content changes should happen under `docs/`. The `site/` directory is generated by MkDocs and should not be edited by hand.

## Local Preview

Install dependencies:

```powershell
pip install -r requirements.txt
```

Run the local development server:

```powershell
mkdocs serve
```

The local preview is usually available at:

```text
http://127.0.0.1:8000/ML-Foundations/
```

To preview from another device on the same network, bind the server to all interfaces:

```powershell
mkdocs serve -a 0.0.0.0:8000
```

## Build

```powershell
mkdocs build --strict
```
