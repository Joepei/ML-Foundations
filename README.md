# ML Foundations

This repository contains Joe Pei's technical writing on machine learning fundamentals, deep learning systems, and transformer implementation details.

The site is built with MkDocs Material and published with GitHub Pages.

Published site URL, once GitHub Pages is enabled:

```text
https://joepei.github.io/ML-Foundations/
```

## Local preview

```powershell
pip install -r requirements.txt
mkdocs serve
```

## Build

```powershell
mkdocs build
```
