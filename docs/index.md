# ML Foundations

<p class="lead">Technical writeups on machine learning fundamentals, transformer architectures, and implementation details by Joe Pei.</p>

This site is a public collection of essays that turn study, implementation, and interview preparation into clear technical writing. The goal is simple: explain core ideas carefully enough that the reasoning is visible.

## Start Here

- [Machine Learning Fundamentals](machine-learning/index.md): supervised learning, generalization, linear models, and tree-based models.
- [Deep Learning and Transformer Systems](deep-learning/index.md): tokenization, transformer components, attention, optimization, and training loops.

## Current Focus

The first version focuses on a clean foundation rather than volume. Some writeups are intentionally concise and will be refined as the material evolves.
